# las 10 reglas fundamentales de la sintaxis de javascript

- las instrucciones terminan con punto y coma ( ; )
- los numeros decimales utilizan el punto ()
- los literales de texto van entre comilas dobles (".......") o simples ('.....')
- se usa let, const o var para declarar variables
- el operador de asignacion es el signo igual (=)
- operaciones aritmeticas: +,-,/,*,%
- las expresiones pueden combinar variables y valores
- comentarios de una linea (//) y multilineas (/..../)
- los identificadores empiezan por letra, guion bajo o dolar ($)
- case-sensitive: javascript distingu entre mayusculas y minusculas(nombre y NOMBRE son diferentes)
